# jobfxxk

把秋招投递从头做到尾的 Claude skill。

你给它一份简历或者几段经历，它帮你整理成信息库、生成可打印的简历、从实时岗位表里筛出匹配的岗位、打开招聘官网把表单填好，最后把这次投递记进进度表。

**提交按钮永远由你自己按。**

---

## 它能做什么

- 把简历或口述经历拆成结构化条目，逐条和你核对，数字逐个确认
- 生成 Word 和 PDF 两个版本，PDF 可直接打印给 HR 看
- 从内置岗位数据源（约 12000 条校招岗位，每日同步）里按经历匹配度筛岗
- 打开招聘官网，填姓名、教育、实习、项目这些文字内容
- 遇到简历上没有、但网申必填的字段，一次性问清并记进信息库，以后不再重复问
- 把每次投递同步进进度表

## 它不做什么

- 不替你点提交、保存、确定——所有提交类按钮都由你自己点
- 不编造你没做过的经历，不改你简历上的任何数字
- 不把你的信息上传到任何地方

## 目录结构

```
jobfxxk/                        ← 这个仓库，不含任何个人信息
├── SKILL.md                    主流程（11 个阶段）
├── references/                 六份细则
├── scripts/                    11 个脚本
├── assets/template/            简历模板（脱敏）
├── config.example.json         配置样例
└── package.json

jobfxxk-data/                   ← 你的数据，与仓库平级，不进 Git
├── config.json                 配置
├── user/                       锚点表、加密后的敏感信息
├── data/                       岗位缓存
└── browser-profile/            自动化浏览器的独立配置
```

**分开放的理由**：`jobfxxk` 里永远是干净的 skill，可以随时发布；你的名字、简历、身份证、登录态全在 `jobfxxk-data` 里，和仓库没有任何物理关系。

`jobfxxk-data` 第一次运行时会自动创建。

---

## 环境要求

- Node.js 18+
- Playwright（驱动浏览器）
- Python 3 + python-docx + pypdf（改简历、验版式）
- Microsoft Word（docx 导出 PDF）
- 一个 Chromium 系浏览器（Edge / Chrome）

---

## 岗位数据源

内置的校招岗位表约 12000 条，实时更新，公开可读，不需要登录。

同步方式：

```bash
node scripts/sync_jobs.cjs --only=jobs
```

原理是用无头浏览器打开表格页拿到访客会话，再在同源上下文里翻页取数，本机解压后存成 JSON。表结构变了会导致同步失败，届时用上次缓存并在结果里标注数据日期。

---

## 隐私

- 个人信息只存本地，仓库里没有任何用户数据
- 证件号、家人信息这类敏感字段单独存一个加密文件，密钥放在系统凭据管理器
- 敏感信息不写日志、不进简历、不出现在任何交付物里

---

## 使用

在 Claude Code / Claude Desktop 里安装为 skill 后，直接说「帮我投简历」即可。第一次会走建档流程。

---

## 免责

岗位信息来自第三方维护的公开表格，时效性由原表维护者决定，投递前请自行确认岗位是否仍在招聘。本工具不保证投递结果。
